# FinFlow 个人记账

## 概述
基于 Flutter 与 SQLite 构建的本地化个人记账应用，专为 STEM 课程研发机构的行政采购工作量身定制。

核心业务场景涉及 **"项目 → 年级 → 课程 → 材料"** 的多级结构：
- **层级关系**：一个项目包含多个年级，每个年级开设不同课程，不同课程可能复用同一种材料。
- **业务逻辑**：根据课程及各年级学生人数，计算所需材料总量进行精准采购与打包发货。

应用帮助清晰记录从日常办公用品到核心课程材料的所有采购收支，实现对复杂项目成本的精细化核算。

## 功能概览

### 账务管理
- **多账本管理**：支持创建多个账本，默认账本受保护不可删除
- **账户管理**：固定账户列表（默认账户 + 公账材料），公账材料不可改名删除
- **智能记账**：
  - 标准计算器键盘，支持加减乘除四则运算（如 `3+5×4` 显示 `32`）
  - 即时计算显示结果
  - 所有分类支持数量录入
  - 课程材料分类支持材料名称智能匹配
- **时间筛选**：首页支持全部/按月/按年筛选账单
- **搜索功能**：按备注/分类/金额实时筛选

### 材料库存
- **基础材料管理**：增删查改、批量导入、xlsx导出分享
- **库存汇总**：已购数量、初始化数量、出库数量、剩余数量
- **库存明细**：入库/初始化/出库流水记录
- **库存初始化**：全量材料列表分页展示，单条修改初始化数量
- **批量出库**：导入模板批量出库，库存不足时支持确认继续

### 项目材料关系
- **关系维护**：项目-年级-课程-材料四级关系管理
- **导入导出**：xlsx格式，按项目名称全量覆盖导入
- **材料校验**：导入时校验材料是否存在于基础材料表

### 出库导出
- **课程出库导出**：导入xlsx自动识别年级，动态生成学生/老师人数输入栏
  - 支持按人/按组双口径计算
  - 导出年级明细 + 出库汇总 Sheet
  - **成本计算 Sheet**：按年级-课程汇总材料总价、每生成本、师均成本、生师比
  - 成本结构分析：最高材料占比、集中度指数(HHI)、最大成本项
  - 课程健康度评分与优化建议
- **账单数据导出**：
  - 筛选日期/账本/账户导出 xlsx
  - 新增归属项目/归属年级/重复材料标记列
  - 表头配色加粗、网格边框、隔行底色样式美化
- **公账材料导出**：公账材料账户账单独立导出

### 数据管理
- **本地化存储**：所有数据存储在本地 SQLite，隐私安全
- **数据备份恢复**：支持数据库备份与恢复
- **Android 分享**：导出文件支持系统分享（微信等）

## 运行环境
- Flutter 3.x
- Android、Windows（Windows 用于调试）

## 快速开始
```bash
# 安装依赖
flutter pub get

# 运行应用
flutter run -d windows

# 打包 apk
flutter build apk --release

# 打包 exe
flutter build windows --release
```

## 项目结构
```
lib\
├── main.dart                         # 应用入口
├── data\
│   ├── record_database.dart          # 数据库核心层（单例、表结构、CRUD）
│   └── transaction_record.dart       # 数据模型定义
└── ui\
    ├── home_page.dart                # 主界面（记账/管理双Tab、搜索、时间筛选）
    ├── record_form_sheet.dart        # 记账弹窗（计算器键盘、分类选择）
    ├── extension_menu.dart           # 扩展功能菜单入口
    ├── base_materials_page.dart      # 基础材料管理页
    ├── material_inventory_page.dart  # 材料库存汇总与明细页
    ├── material_inventory_init_page.dart # 库存初始化页
    ├── project_material_relation_page.dart # 项目材料关系维护页
    ├── course_outbound_import_page.dart # 课程出库导出页
    └── line_account_page.dart        # 公账材料管理页

assets\
└── finflow.db                        # 预置数据库文件
```

## 数据表结构
详见 `数据库字典.md`，主要表包括：

| 表名 | 说明 |
|------|------|
| records | 交易记录（金额、分类、日期、备注、数量、账户、账本） |
| bills | 账本 |
| accounts | 账户 |
| base_materials | 基础材料（名称、单位、初始化数量） |
| outbound_records | 出库记录 |
| project_material_relations | 项目材料关系（项目/年级/课程/材料） |
