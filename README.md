# FinFlow 个人记账

## 概述
这是一个基于 Flutter 与 SQLite 构建的本地化个人记账应用，专为我在 STEM 课程研发机构的行政采购工作量身定制。

作为行政负责人，我需要管理复杂的课程材料采购流程。业务场景涉及 **“项目 → 年级 → 课程 → 材料”** 的多级结构：
- **层级关系**：一个项目（如“正大项目”）包含多个年级，每个年级开设不同课程，不同课程可能复用同一种材料。
- **业务逻辑**：根据客户订购的课程及各年级学生人数，计算所需材料总量进行精准采购与打包发货。

本应用旨在解决这一场景下的财务记录痛点，帮助我清晰记录从日常办公用品到核心课程材料的所有采购收支，实现对复杂项目成本的精细化核算。

为覆盖全流程的财务管理需求，本应用重点关注以下三类收支记录：

1.  **项目与供应链支出**：
    *   **核心材料**：课程研发所需的各类原材料采购费用。
    *   **物流与加工**：采购及发货产生的快递物流费、线稿资料的打印加工费。
    *   **临时劳务**：高峰期聘请兼职人员协助打包分发的劳务费用。
2.  **行政与运营支出**：
    *   **日常办公**：办公用品采购、打印耗材等。
    *   **员工福利**：饭卡充值、咖啡茶歇采购、公司团建活动费用。
3.  **差旅与交通**：
    *   **公务出行**：个人因公出差产生的交通及相关差旅费用。

## 功能概览
- **多账本与多账户管理**：支持创建多个账本（如日常、旅行、装修）与多个账户（如微信、支付宝、银行卡），实现精细化资产管理。
- **智能记账交互**：
  - 底部弹层 + 自研数字键盘，支持加减法运算（如输入 `12+8` 自动计算为 `20`）。
  - 支持“再记一笔”功能，保存当前记录后保留界面，仅清空金额与备注，提升连续记账效率。
  - 自动记忆上次使用的分类与账户。
- **数据查询与检索**：
  - 首页按日期分组展示交易记录，并显示每日收支汇总。
  - 支持按关键字搜索备注与金额。
  - 下拉加载更多历史数据，优化长列表性能。
- **数据管理**：
  - 支持记录的编辑与长按删除。
  - 账本与账户的管理（新增、修改名称、删除），默认账本/账户受保护不可删除。
  - 账单数据导出：支持筛选日期、账本、账户导出为 Excel (.xlsx) 文件，方便二次分析。
  - 数据导入：支持从 Excel 文件导入数据（开发中/已预留入口）。
- **本地化存储**：所有数据存储在本地 SQLite 数据库中，隐私安全，无网络依赖。

## 运行环境
- Flutter 3.x
- Android、Windows（Windows 用于调试与桌面体验）

## 快速开始
1. 安装依赖
   ```bash
   flutter pub get
   ```
2. 运行应用
   ```bash
   flutter run -d windows
   ```
3. 打包 apk
   ```bash
   flutter build apk --release -v
   ```

## 数据结构设计
### 交易记录表 (records)
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | INTEGER | 主键，自增 |
| bill_id | INTEGER | 关联账本 ID |
| account_id | INTEGER | 关联账户 ID |
| type | TEXT | 交易类型 (income / expense) |
| amount | REAL | 交易金额 |
| category | TEXT | 交易分类 |
| date | TEXT | 交易日期 (ISO 8601 字符串) |
| note | TEXT | 备注信息 |

### 账本表 (bills)
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | INTEGER | 主键，自增 |
| name | TEXT | 账本名称 |
| is_default | INTEGER | 是否默认账本 (0/1) |

### 账户表 (accounts)
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | INTEGER | 主键，自增 |
| name | TEXT | 账户名称 |
| is_default | INTEGER | 是否默认账户 (0/1) |

## 交互细节
1. **记账流程**：点击首页“记一笔” -> 弹出面板 -> 输入金额（支持加减） -> 选择分类/账户/日期 -> 保存。
2. **列表操作**：
   - **点击**：进入编辑模式。
   - **长按**：弹出删除确认框。
   - **搜索**：顶部搜索框输入关键字，实时过滤显示相关记录。
3. **管理功能**：
   - 在“管理”页签可切换当前账本与账户。
   - 长按账本/账户条目可进行修改名称或删除操作（默认条目除外）。
   - 删除账本时，若账本内有数据，会触发二次确认或迁移提示。
